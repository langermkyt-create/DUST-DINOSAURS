# DUST & DINOSAURS
A 3D frontier adventure set in an alternate 1897 American West where dinosaurs have always been part of the living ecosystem.

## First playable slice
- Walkable 3D frontier settlement of Red Rock, Arizona.
- First-person movement, sprinting, jumping and mouse look.
- Frontier buildings, railroad, locomotive, telegraph poles, desert rocks, mesas and cactus.
- A small triceratops family and a distant tyrannosaur silhouette.
- Warm sunset atmosphere, shadows, sky and cinematic HUD.

## Build
Open the project in Godot 4.4.1 or later and run scenes/main.tscn.
GitHub Actions exports a Windows x86_64 executable on pushes to main.

This is the first vertical-slice foundation, not the final world-scale game. Art, animation, narrative and simulation systems will be expanded in subsequent iterations.
